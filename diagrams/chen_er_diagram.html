📐 Peter Chen ER Notation Components

In the Peter Chen model, database entities, attributes, and associations are visually mapped using strict geometric symbols:

Symbol Component Blood Bank Schema Example
Rectangle Entity Set Donor, Donation, Blood_Stock, Hospital_Request
Diamond Relationship Makes (1:N), Increments (N:1), Supplies (1:N)
Oval Attribute Name, Age, Units_Donated, Hemoglobin
Underline Key (PK) Donor_ID, Donation_ID, Blood_Group, Request_ID
1 : N Cardinality 1 Donor can make N Donations; 1 Stock supplies N Requests

🏥 Entities & Relationship Specifications

  • DONOR (1:N with DONATION): Represents registered voluntary blood donors. Attributes: donor_id (PK), name, age (18-65), gender, contact_number, email, city, registration_date.
  • DONATION (N:1 with BLOOD_STOCK): Captures clinical donation sessions. Attributes: donation_id (PK), donation_date, units_donated, hemoglobin_level (≥12.0 g/dL), phlebotomist_name, remarks.
  • BLOOD_STOCK (1:N with HOSPITAL_REQUEST): Central cold storage inventory categorized by 8 blood groups (A+, A-, B+, B-, AB+, AB-, O+, O-). Attributes: blood_group (PK), available_units, minimum_threshold, last_updated.
  • HOSPITAL_REQUEST: Emergency and routine requisitions from healthcare facilities. Attributes: request_id (PK), hospital_name, units_requested, request_date, urgency_level, status, fulfillment_date, authorized_by.

🎓 Academic Alignment & BCNF Normalization

The schema satisfies Boyce-Codd Normal Form (BCNF) and 3NF. Every functional dependency \(X \rightarrow Y\) has a candidate key as its determinant:

• DONOR: donor_id → {name, age, gender, contact, email, city, reg_date}
• DONATION: donation_id → {donor_id, blood_group, donation_date, units, hgb, phleb}
• BLOOD_STOCK: blood_group → {available_units, minimum_threshold, last_updated}
• HOSPITAL_REQUEST: request_id → {hospital, blood_group, units, date, urgency, status}

Zero transitive dependencies exist. Referential integrity is strictly maintained with Foreign Key constraints and automatic inventory synchronization triggers.
